## 🛠️ Git Commands Learned So Far

| Command | Kaam |
|---------|------|
| `git init` | Naya repo banao |
| `git config` | Name & email set karo |
| `git add` | File staging mein daalo |
| `git commit -m ""` | Change save karo |
| `git status` | Current state dekho |
| `git log` | Commit history dekho |

---

## 💡 Key Concepts

| Concept | Matlab |
|---------|--------|
| **Repository** | Project ka folder jahan Git kaam karta hai |
| **Commit** | Ek saved snapshot — time machine ka point |
| **Staging Area** | Commit se pehle files yahan aati hain |
| **Branch** | Alag version banane ke liye |
| **Merge** | Do branches ko ek mein milana |
| **Remote** | GitHub pe rakha repo |
| **Push** | Local se GitHub pe bhejna |
| **Pull** | GitHub se local pe lana |

---

## 🔄 Git Ka Basic Flow

```
Working Directory → git add → Staging Area → git commit → Local Repo → git push → GitHub
```
